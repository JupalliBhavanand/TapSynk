# Feature recovery

The local `cc43763` snapshot contains the requested Calendar/Meet, notifications,
email-signature editor, image exports, and related UI changes. A subsequent
rebase onto `30d0f8e` left those changes outside the active branch.

The recovery applies the feature diff from `55d3216` to `cc43763` on top of
`30d0f8e`, preserving the newer fulfillment permissions, analytics, and footer.
The dashboard navigation combines fulfillment links with the recovered
signature and notification links.

- Working branch: `codex/restore-requested-features`
- Protected source snapshot: `codex/recovered-feature-snapshot`
- `.env` and its credentials were not overwritten.
- `.env.example` documents the shared `tapsynkai@gmail.com` sender. Use an app
  password generated by that account to enable it; the existing sender remains
  active until the real environment is updated.
- Calendar/notification schema is included in migrations 0007 and 0008. Apply
  these only if they have not already been applied to the target database.

The test suite covers signature links, public email images, photo styles,
Calendar/Meet synchronization, booking emails, owner notifications, and the
existing voice/payment behavior. New regression tests are included in npm test.
